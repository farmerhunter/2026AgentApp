# V3：多用户真实场景版

**状态：Planned / 尚未启动。**

V3 的方向是把 V2 的单用户真实闭环扩展为可承载真实家庭或学习场景的多用户系统。当前只保留方向和启动条件，不预先确定数据库、云厂商、框架或详细文件结构。

## 启动条件

- V2 的真实学习闭环已经稳定运行并有重复使用证据；
- 已明确真实用户、角色关系和数据责任人；
- 已验证多用户需求，而不是只为未来想象增加复杂度；
- 产品负责人确认真实数据、外部费用、账号权限和迁移风险。

## 预期能力边界

- 用户鉴权、学生/家长/教师角色和授权；
- 多用户数据隔离与最小权限访问；
- 私有对象存储、生产数据库和后台任务队列；
- 数据查看、更正、导出、删除和保留策略；
- 审计、备份、恢复和迁移；
- 模型调用的隐私、成本和配额控制。

## 启动时需要建立的文档

只有 V3 正式启动后再创建：

- 身份与权限 contract；
- 数据生命周期和隐私说明；
- 生产架构与迁移计划；
- 运行、备份和灾难恢复手册。

V3 实现必须保持 V2 已验证的 Hermes 领域语义；更换存储、认证或模型 Provider 不应重写 finding、memory candidate、insight 和 action 的业务含义。

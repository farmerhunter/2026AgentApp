# 从 V2 明确延后到 V3 的能力

**状态：Planned backlog。** 本清单用于防止 V2 为赶终评而裁剪的内容在以后规划时丢失；它不是 V3 的实现承诺或优先级排序。

## 教材与输入

- 在线教材 PDF 上传、OCR、切页、分段、进度、失败重试和导入后台；
- 多教材、多版本、多年级和 2–3 个以上学科；
- PDF 练习、多图片批量、对象存储和完整文件生命周期；
- 自动判错、标准答案匹配和复杂人工纠错流程。

## 学习记忆与智能

- 记忆编辑、合并、去重、冲突处理和自动 consolidation；
- 长期画像、跨学科推理和自动建议升级；
- 定时周报、报告历史、多格式服务端 PDF/DOCX；
- 大规模 Skill eval、A/B、自动优化或自动进化；
- Hermes Gateway、消息系统、自由 Agent 循环和动态工具市场。

## 用户、安全与隐私

- 正式账号体系、学生/家长/教师角色和细粒度授权；
- 多用户数据隔离、审计、导出、删除、保留策略和监护人同意；
- production 级内容安全、限流、防滥用、密钥轮换和合规流程。

## 基础设施与运维

- COS/其他对象存储、PostgreSQL、Redis 和独立后台 worker；
- 并行队列、自动重试、优先级、取消、详细进度和任务历史；
- 高可用、横向扩展、完整监控告警、灾备和自动化迁移。

## V3 规划时的重新评估

V3 启动时应基于真实用户和 V2 使用证据重新排序，而不是逐项照搬。任何能力仍需说明用户问题、数据责任、成本、迁移和验收方式。

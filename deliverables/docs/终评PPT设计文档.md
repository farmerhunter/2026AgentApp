## 1. 统一口径

| 层 | 名称 | 表述 |
|---|---|---|
| 产品 | 学途智伴 | 面向初中生的 AI 学习智能体应用 |
| 智能体引擎 | Hermes | app 内置的 LLM 智能体引擎，承载 Skill、上下文、校验与记忆语义 |
| 模型 | DeepSeek | Hermes 当前配置的推理 Provider，应用不直接调用 |
| 知识地图 | Roadmap / 知识地图 | 教材结构化后的章节-小节-知识点地图 |

关键术语：错题分析产出 **local findings（局部发现）**、**memory candidates（待确定记忆）**、**action candidates（行动候选）**；周报通过 consolidation 把多个 findings 合并成 **insights（聚合见解）**。

## 2. 逐页设计

### P1 目录

三部分：01 创作思想（为什么做、灵感与机会）；02 功能介绍（教材导入 / 试卷错题导入 / 周报的底层逻辑）；03 创作方式（人机协作与工程方法）。

### P2 第一部分标题：创作思想

大字「01 · 创作思想」，副题一行："从一个中学生自己的学习困扰出发"。

### P3 用户痛点

三张卡：太耗时（一道道抄写整理）；复习不及时（写完就忘）；看不出问题（只知道错了哪道，看不到深层原因）。底部一句：于是想做一个能真正帮上忙的工具。

### P4 机会：AI 能完成以前做不到的事

两栏对比：以前做不到（手动整理费时、识别不准、无法持续记忆、无法结构化分析）；现在 AI 能做（自动切题、理解教材、持续记忆、生成结构化建议）。落点：所以设计出用 AI 智能体辅助学习的 app。

### P5 第二部分标题：功能介绍

大字「02 · 功能介绍」，强调"讲底层逻辑，不讲表面操作"。列三个功能：教材导入 / 试卷错题导入 / 周报。

### P6 教材导入

底层逻辑：上传教材电子版 → Hermes 生成知识地图（Roadmap），把章节、小节、知识点整理成结构化地图，并分析各知识板块。作用：给后面的错题分析提供"学什么"的参照坐标系。

### P7 试卷 / 错题导入

底层逻辑：试卷照片 → AI 自动切题 → 学生指定错题和重点题 → 上传给 Hermes → 对照 Roadmap 找到对应知识点模块 → 分析深层问题 → 记为 local findings + memory candidates + action candidates。重点句：深层问题先记为"局部发现"，不直接升级成"见解"。

### P8 周报

底层逻辑（依据 skill / prompt / contract / 样例）：

1. 输入本周 findings、重点题、备注、记忆、知识地图；
2. consolidation：按学科、知识点、问题模式分组，识别重复或高优先级模式；
3. 把多个 findings 合并为 insights；
4. 输出跨学科总览 + 各学科分区 + 重点题 + 建议 + 下周行动。

规则：不重新分析原始材料；不把一次小错夸成长期趋势；无数据学科显示 no_data；行动少量、可执行、可追溯到来源。

### P9 第三部分标题：创作方式

大字「03 · 创作方式」。

### P10 与 AI 开发

人负责（需求 / 架构 / 任务拆解 / 验收），AI 负责（编码 / 调试 / 验证 / 方案）。底部一句：我定方向与规则，AI 负责实现。

### P11 如何保证 AI 产出准确（人话版）

四张卡用人话讲：先把要做的事写清楚；给每个任务列验收清单；让 AI 输出标准格式而不是自由作文；每一步都要检查通过才算完。总结一句：不是让 AI 随便写，而是给它明确的题目、格式和及格线，再逐项验收。

### P12 一个完整的任务闭环

我写 issue（目标/验收/边界）→ AI 实现 → 构建校验 → 我审核 → 通过关闭。右侧示例 Issue #7。

### P13 AI 辅助的人工确认（重点）

为什么需要人工确认重点题：OCR/模型会看错（手写、批改、扣分原因不可靠）；"哪题重要"必须由学生判断；确认后才成为可信输入。结论：AI 做感知和总结，人做关键判断，人工确认是质量闸门。

### P14 从错题到可执行行动

把"错在哪"推进到"为什么错"和"下一步怎么练"。三点：可追溯、可执行、可复查。右侧对比普通错题本 vs 学途智伴。

### P15 从学习证据到行动建议

分层语义模型 + 三条规则：finding ≠ insight；不直接写长期记忆；证据不足保留不确定。配 evidence_to_action_flow 图。

### P16 Hermes：app 内置的 LLM 智能体引擎

调用链：Web/API → HermesBridge → Hermes → DeepSeek；三个 Skill；记忆规则（SQLite 为准、学生确认后才复用）。

### P17 总结

三个收获（工程方法 / 驾驭 AI / AI 定位）+ 收尾一句："人定方向，AI 实现，工程方法保障质量" + 作品链接。

# “学途智伴”终评展板

本目录用于制作 2026 北京青少年人工智能应用实践活动终评展板。成品尺寸为高 1200 mm、宽 900 mm，竖版。

## 当前状态

阶段 B 已完成：展板已绑定最终 `main@3ccefce`，三张关键界面来自最终版 Web UI 和已验收 A/B 结果的隔离回放。回放只使用原创模拟材料和仓库中已保存的 Hermes 输出，没有新增 OCR/Hermes 调用，也不把 fixture 结果当作新的模型证据。

- `poster-content-v01.md`：第一版展板文案
- `poster-content-v02.md`：阶段 B 文案与截图说明
- `poster-v01.svg`：阶段 A 的 900 × 1200 mm 草图
- `poster-v02.svg`：已替换正式程序截图的阶段 B 版本
- `asset-register.md`：素材来源、知识产权与待补项登记
- `assets/`：SVG 使用的本地素材副本，移动展板时需与 SVG 一起保留
- `previews/`：渲染预览
- `capture/`：可复现的隔离回放、浏览器采集、裁切和预览脚本

## 分阶段交付

### 阶段 A：现在完成

- 确定“我的问题 → 我的创作方法 → 我的作品 → 我的实践验证 → 我的发现与收获”的主线
- 完成 900 × 1200 mm 版面草图
- 放入原创 A/B 模拟练习材料
- 以输出结果代替没有解释力的小样本统计
- 给三张正式程序截图和公开体验二维码保留明确占位
- 进行整板预览和缩印可读性检查

### 阶段 B：已完成

- 使用最终验收版本回放 A/B 原创模拟练习和已保存输出
- 截取“导入与确认、分析与记忆、学习周报”三组正式程序图
- 用正式截图替换展板占位框，并核对截图与文字描述一致
- 保存原始截图、展板裁切图、采集清单和裁切清单
- 完成整板及 A4 缩印复检

说明：阶段 B 采用已验收结果回放，不是 2026-09-02 的新 OCR/Hermes 实验。完整原始输出仍可从仓库的 E5 learning story 追溯。

### 阶段 C：公开链接确认后

- 生成并实测公开体验二维码
- 完成隐私、版权和素材许可复核
- 输出 A4 缩印校样和 900 × 1200 mm 的 1:1 印刷 PDF
- 建议文印店采用哑光 PP 背胶裱 5 mm KT 板，成品尺寸 90 × 120 cm

## 当前边界

本版中的 A/B 练习是原创模拟材料，只用于说明系统的工作方式；它们不代表大规模测试，也不用于声称学习成绩提升。正式程序截图已经补入；公开体验二维码仍待阶段 C。

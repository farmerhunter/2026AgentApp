## 4. 八道重点题：能说什么，不能说什么

### A06：根式相加的错误步骤

- 可见证据：明确写出 `√18＋√8＝√(18＋8)`。
- 可以指出：本题这一步把根式相加误写为被开方数相加；正确处理是先化简，再合并同类根式。
- 有用帮助：对照 `3√2＋2√2`，解释相同根式部分对应系数相加。
- 不能断言：学生长期基础差、态度不认真，或过去已经反复犯错。第一批尚无历史证据。

### A09：方法选对，但分母乘积算错

- 可见证据：分子分母同乘 `√5＋√2` 的设置正确；随后把 `(√5－√2)(√5＋√2)` 写成 `5＋2`。
- 可以指出：错误定位在这一步乘积计算，应为平方差 `5－2`。
- 有用帮助：指出共轭式的交叉项抵消，并核对分母；不必重新讲一套与本题无关的方法。
- 不能断言：完全不会分母有理化、一定不懂平方差公式，或为了更深分析补写学生没有表达的想法。记住公式但一次写错也是可能原因。

### A10：求出斜率后没有确定截距

- 可见证据：斜率 k＝2 正确；没有出现求 b 的步骤，直接给出 y＝2x。
- 可以指出：当前表达式不经过给定两点，需要继续代入确定 b＝2。第二问是在错误表达式上的后续结果，不需要拆成另一条主要 finding。
- 有用帮助：说明只知道斜率还不足以从这些条件确定本题直线；用给定点核验表达式。
- 不能断言：学生不知道所有一次函数都含截距、长期只会正比例函数，或虚构一句“学生认为 b＝0”。本题只有遗漏证据，没有该心理解释。

### B06：在不同题目中再次出现相同处理方式

- 可见证据：明确写出 `√27＋√12＝√(27＋12)`，与 A06 的运算方式相同，但不是同一道题重跑。
- 可以指出：本题的局部错误；若本次实际输入包含已接受、且能回溯 A06 的相关记忆，可限定为“两批题中都出现了这种处理方式”。
- 有用帮助：先将两项化简成 `3√3` 和 `2√3`，再说明合并方法。
- 不能断言：无历史输入时仍声称“又错了”；有两次证据也不能扩大成所有根式运算都不会。

### B09：只有错误答案，不能补写过程

- 可见证据：只写－3，没有等式、演算或备注。
- 可以指出：正确结果为 3；解释平方差关系。当前错因保留为不确定。
- 不能断言：一定算成 `4－7`、一定漏负号、一定重复 A09 的错误。尤其 A09 可见的错误是平方和，不是 B09 的已知计算路径。
- 即使周报同时拿到 A09 和 B09，也最多指出知识内容相关，不能说两题已经证明相同错因。

### B10：局部改善与本次错误并存

- 可见证据：本次正确计算 k、代入求 b、写出 y＝2x＋3；第二问代入和乘法正确，最后 `－4＋3＝－7` 不成立。
- 可以指出：本题局部错误在最后一步有理数加法；若带有 A10 的已接受记忆，可以说明本次已完整求出两个参数，不应再沿用“遗漏截距”作为主要错因。
- 有用帮助：保留正确的建模/代入步骤，核对 `－4＋3`，得到－1。
- 不能断言：一次函数已完全掌握、上次建议已经执行并奏效，或这次是“态度差/粗心”。一个可见计算错误不足以判定稳定习惯。

### C05：方法变化，但系数计算仍错

- 可见证据：本次把 `√48` 和 `√75` 正确化为 `4√3` 和 `5√3`，没有再把被开方数直接相加；随后把系数和写成 8。
- 可以指出：本题错误定位在同类根式系数相加；若实际输入包含 A06/B06 的来源和已接受记忆，可以说本次采用了不同且正确的化简方法。
- 不能断言：二次根式已经掌握、A/B 的问题已经被干预解决，或把本次错误继续归为“根号内直接相加”。一次变化只支持局部描述。

### C06：截距步骤再次完整，负数加法重复

- 可见证据：本次正确求出 k＝3、b＝2 和 y＝3x＋2，代入 x＝－2 后把 `－6＋2` 写成 `－8`。
- 可以指出：若实际输入包含 A10/B10 的来源和已接受记忆，截距步骤在 B/C 两批均已完整；B10/C06 两次可见错误都发生在负数加法的最后一步。
- 不能断言：一次函数已经稳定掌握、负数运算长期薄弱，或本次错误只是“粗心”。两次证据只能支持有边界的重复观察。

## 5. 记忆选择与周报的检查点

第一批优先考虑 A06、A10 中有来源、可供以后比较的观察，最多接受两条。不为凑数接受候选；先检查真实模型内容是否准确，接受后才用实际记忆 ID 带入第二批。A09 的 finding 仍进入本周周报，即使它没有成为记忆。

核对者可以期待周报完成以下工作，但不能把本段作为提示给模型：

1. 说明分析来自两批练习中的 6 道已确认错题，不声称代表所有作答或给出掌握率。
2. 用 A06/B06 的具体步骤支持根式相加问题的重复，而非只统计错误标签。
3. 用 A10/B10 支持“确定函数表达式这一步有所变化”，同时保留 B10 的计算问题。
4. 对 B09 保留错因不确定，不借 A09 或其他历史强行归因。
5. 给出 1–2 项可执行建议；例如优先核对根式加法的处理方法，再对函数求值中的符号计算增加一步检查。允许其他同样有依据的排序和措辞。

没有要求生成长期人格标签、行动完成记录、跨周趋势、自动记忆更新或额外澄清问题。第二批作答是人工构造的局部变化，不是干预有效的实验证据。

现场导入 C 后，核对者应期待一份新生成的周报，而不是覆盖后仍无法区分的新旧内容。它至少应满足：

1. 证据范围明确更新为 3 批练习、8 道经确认错题；不把 C01–C04 算作已分析正确题。
2. C05 被描述为根式处理方法的局部变化和当前系数计算错误，不说旧错误第三次重复，也不宣称掌握。
3. C06 与 B10 的负数加法错误可形成有来源的两次重复；A10 的截距遗漏不应继续作为 C06 的当前错因。
4. B09 仍保持“无过程、错因不确定”，不能因 C 的加入而被追溯性补写原因。
5. UI 能看出新周报生成时间晚于基线，并展示“3 批、8 道经确认错题”或等价的证据范围。

这些是人工验收边界，不是预制模型答案。实际 Hermes 可以采用不同但同样准确、有证据的措辞。

# E5 两批仿真练习文字稿

状态：文字材料 v1，待产品负责人审阅；不是试卷图片、OCR 实测记录、模型输出或 E5 验收证明。

本目录落实 [E5 核心能力设计](../../../docs/v2/epics/e5-hermes-learning-analysis.md)中的两批学习故事：每批 10 题，约 3 道重点错题；先形成局部发现和必要记忆，再比较后续作答，最后生成简洁周报。

## 阅读与使用

- [练习 A：题目与模拟作答](batch-a.md)
- [练习 B：题目与模拟作答](batch-b.md)
- [人工核对说明](reviewer-guide.md)：20 题参考答案、6 道重点错题的证据边界、记忆与周报检查要点。**不得作为模型输入。**

两份练习均为 4 道选择题、4 道填空题、2 道解答题，二次根式和一次函数各 5 题。没有真实姓名、学校、照片或隐私数据。所有作答都是合成的；A/B 表示模拟学习顺序，不是已经发生的学习日期或干预记录。

每题固定编号用于文字稿之间核对。将来通过 OCR 进入产品时，应记录它与实际 upload/question/finding ID 的对应关系，不把 A06 等直接冒充数据库中的既有 ID。

## 输入与参考严格分开

文字试验准备时，仅从练习稿取出经人工确认的错题题干、必要选项、学生答案及“纸上演算”。这些演算属于模拟学生实际写在纸上的内容，不是给模型的解释。题目标题、目录、材料说明和核对文档不属于学生作答。

不要把整份 README 或人工核对说明交给模型；不要自动把整份 10 题当成 10 道错题；也不要从参考答案中补写学生步骤。B09 没有过程，输入就应保留没有过程。

第一批记忆由真实分析产生、经用户接受后才能用于第二批。核对文档中的候选意图、预期变化和参考措辞不能预填成已接受记忆，也不能伪造 finding/memory ID。暂时没有生成并接受记忆时，第二批只能叫“无历史文字分析”，不能声称已验证记忆复用。

## 这个小故事希望检验什么

- A06 与 B06：不同题目里出现相同的错误运算步骤，能否识别有证据的重复。
- A10 与 B10：此前缺少确定截距的步骤，后续已完整求出表达式、但另有计算错误，能否识别局部变化而不沿用旧错因。
- A09：能够选择有理化方法，但乘积计算有误，能否定位到具体步骤而非笼统说“不会有理化”。
- B09：仅有错误答案，即使其他题出现过乘法问题，也不能编造本题的计算路径。

这些是材料设计意图，不是实际 findings。只有检查真实输出后，才能记录模型是否达到目标。20 题中的正确作答是试卷背景，V2 当前不分析它们；周报不能据此宣称掌握了整份试卷表现或给出可靠正确率。

## 已做检查与仍未做的事

- 已做：同一编写会话对 20 题逐题推导，并用本地算术检查选择题唯一性、数值和关键等式；自查正好 6 道错题、两类知识各 10 题，以及所有示例 ID/交叉链接。
- 未做：独立人工复核、产品负责人对拟真程度的确认、Hermes 内容验证、OCR/切题、试卷排版与图片生成、真实持久化和周报验收。
- 这套材料已经公开给开发者，不是盲测集或未见题。可用于开发与展示，不把在它上面的表现包装为普遍准确率。

目前只交付文字稿与核对说明，不包含模型调用脚本或预制 findings/周报。后续若制作图片，应在选择/填空题附近保留简短演算位置，为 A09/A10、B09/B10 留出解答区域；不挤压字迹，不用跨题大面积涂改制造识别障碍。拟真和切题效果必须另行实测，不能由文字检查代替。

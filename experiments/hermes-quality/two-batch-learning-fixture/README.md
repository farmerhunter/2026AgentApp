## 阅读与使用

- [练习 A：题目、模拟作答与批改](batch-a.md)
- [练习 B：题目、模拟作答与批改](batch-b.md)
- [人工核对说明](reviewer-guide.md)：20 题参考答案、6 道重点错题的证据边界、记忆与周报检查要点。**不得作为模型输入。**

两份练习均为 4 道选择题、4 道填空题、2 道解答题，二次根式和一次函数各 5 题。没有真实姓名、学校、照片或隐私数据。所有作答和批改都是合成的；A/B 表示模拟学习顺序，不是已经发生的学习日期或干预记录。

每题固定编号用于文字稿之间核对。将来通过 OCR 进入产品时，应记录它与实际 upload/question/finding ID 的对应关系，不把 A06 等直接冒充数据库中的既有 ID。

## 批改痕迹与记录

按“学生已经作答、教师已经初批、学生尚未订正”的试卷制作。每题 5 分、每卷 50 分；两卷均为 39/50，卷首显示总分，题旁保留红笔勾叉、部分得分和少量“订正”提示，卷末有简短批改记录。评分细则放在人工核对说明，不印上试卷。

题干、学生笔迹、教师红笔分三层；教师只批改，不代写标准解法、深层错因、历史重复或进步结论。订正区留白，无复批，不伪造行动完成记录。制作图片时，“教师红笔：……”是制图说明，实际呈现其中的符号、分数和短评，不把整段说明渲染到纸上。

部分得分题仍是待确认错题。两卷同分也不能说明学习没有变化：这里的分数只是模拟教师评分，既不是系统自动判分，也不是可据以判断整体学习趋势的数据源。本轮不增加评分、批改记录管理或行动反馈 UI。

## 输入与参考严格分开

文字试验准备时，仅从练习稿取出经人工确认的错题题干、必要选项、学生答案及“纸上演算”。这些演算属于模拟学生实际写在纸上的内容，不是给模型的解释。题目标题、目录、材料说明、教师批改和核对文档不属于学生作答。

真实图片路径保留红笔痕迹，供 OCR/切题与人工确认核对；不能为模拟已实现“来源分离”而提前擦掉红笔。确认时检查红笔文字或分数是否混入学生答案；当前 E4 只允许补录缺失答案，不能编辑已有 OCR 答案，因此混入时应记录识别问题，不能假定已有通用编辑功能。先检查图片和切题质量，若确需扩展编辑流程，另行讨论，不作为 E5 的隐含 UI 任务。教师批注不能冒充学生过程或模型自己的发现，本组文字质量试验不把批注、分数和批改汇总作为 Hermes 输入。是否能在带红笔的图片上正确识别，仍须实测。

不要把整份 README 或人工核对说明交给模型；不要自动把整份 10 题当成 10 道错题；也不要从参考答案中补写学生步骤。B09 没有过程，输入就应保留没有过程。

第一批记忆由真实分析产生、经用户接受后才能用于第二批。核对文档中的候选意图、预期变化和参考措辞不能预填成已接受记忆，也不能伪造 finding/memory ID。暂时没有生成并接受记忆时，第二批只能叫“无历史文字分析”，不能声称已验证记忆复用。

## 这个小故事希望检验什么

- A06 与 B06：不同题目里出现相同的错误运算步骤，能否识别有证据的重复。
- A10 与 B10：此前缺少确定截距的步骤，后续已完整求出表达式、但另有计算错误，能否识别局部变化而不沿用旧错因。
- A09：能够选择有理化方法，但乘积计算有误，能否定位到具体步骤而非笼统说“不会有理化”。
- B09：仅有错误答案，即使其他题出现过乘法问题，也不能编造本题的计算路径。

这些是材料设计意图，不是实际 findings。只有检查真实输出后，才能记录模型是否达到目标。20 题中的正确作答是试卷背景，V2 当前不分析它们；周报不能据此宣称掌握了整份试卷表现或给出可靠正确率。
